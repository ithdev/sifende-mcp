# Seguridad

Para que una vulnerabilidad no quede expuesta antes de corregirla, reportala en privado, no en un issue público.

Usá **Report a vulnerability** en la pestaña [Security](https://github.com/ithdev/sifende-mcp/security) del repo.
Incluí la versión del servidor MCP, los pasos para reproducirla y el impacto que ves.

Solo la última versión publicada de `@sifende/mcp` recibe correcciones de seguridad.

Si la vulnerabilidad está en la API de Sifende y no en el servidor MCP, reportala por el mismo canal.
